Closing the loop with Phase 1

How it was built

  • Images are rendered from the Phase-1 simulator's CD and LER: correlated edge roughness, bright SEM edge bands, charging trails, beam blur, shot noise and scan-line jitter. Defects are drawn with their pixel labels.
  • Training: 2,400 images, 300 for validation; test: 900 images, 150 at each noise level. Nothing here comes from a real SEM.
  • CD comes from the 0.5 crossing of the line probability on every scan row, skipping rows that touch a predicted defect. Both methods get one constant offset calibrated on the validation set, as a real CD-SEM is calibrated against reference metrology.
  • The classical baseline smooths five scan lines, finds the bright edge peaks with sub-pixel fits and rejects outlier widths. It does not correct LER for noise, which many production tools now do.
